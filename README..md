# Knowledge graph on Indian Bail Judgements

## Pre-requisites

### 1. Neo4j (Graph based Database)

1. This database is going to store all the information of the judgements and inferred relationships in graph format.
2. You can use `docker-compose.yml` file to run the Neo4j database in a docker container. OR, You can also use Neo4j Desktop or Neo4j Aura cloud service.
